# لندینگ عمومی و دانلود نصب‌کننده

`https://gym.academyr.ir/` یک صفحهٔ معرفی عمومی است که **بدون ورود** باز می‌شود. پنل مدیریت (`/dashboard`، `/licenses`، `/updates`، `/tickets`، `/help`) پشت همان ورود مالک است و هیچ حساب دیگری ساخته نمی‌شود.

## ساختار
| مسیر | توضیح |
|---|---|
| `/` | لندینگ (فایل `server/public/landing.html`) |
| `/icon.png`، `/icon-mark.png`، `/icon-mark-sm.png` | آیکون برنامه و نشان |
| `/img/*` | تصاویر لندینگ: عکس‌های فیتنس + اسکرین‌شات‌های واقعی برنامه |
| `/download/info.json` | نسخه، حجم، تاریخ و sha256 نصب‌کننده |
| `/download/GymPro-Setup.exe` | نصب‌کننده |
| `/download/GymPro-Setup.exe.sha256` | چک‌سام |
| `/login` | ورود مالک (فقط مالک) |

## پالت رنگی
رنگ‌ها از آیکون برنامه گرفته شده‌اند:

| نقش | مقدار |
|---|---|
| صورتی (اصلی) | `#ff0057` |
| بنفش | `#a34eff` |
| آبی آسمانی | `#53a5ff` |
| پس‌زمینه | `#0a0c12` |

گرادیان `#ff0057 → #a34eff → #53a5ff` در عنوان، دکمهٔ اصلی و نوارهای جداکننده استفاده می‌شود.

## محتوا
- **قهرمان:** عنوان سه‌خطی، توضیح، دو دکمه، چهار آمار، و پنجرهٔ داشبورد.
- **۱۲ قابلیت** با آیکون و شمارهٔ فارسی.
- **نوار عکس تمام‌عرض** با نقل‌قول.
- **تصاویر واقعی برنامه:** اعضا، تردد (اثر انگشت)، کمدها، لایسنس — هر کدام با عکس گرفته‌شده از خود برنامه (نه ماکت).
- **بخش دانلود** با مشخصات زندهٔ فایل از `info.json`.
- **پنل مالک** با توضیح محدودیت دسترسی.
- **پرسش‌های رایج** با `<details>`.

## انتشار نسخهٔ جدید
```bash
# ۱) نسخه را بساز و منتشر کن
node scripts/release.mjs 1.2.3 "یادداشت"

# ۲) نصب‌کننده را برای دانلود سایت آماده کن
python scripts/stage-download.py     # server/downloads/ + info.json + sha256

# ۳) کپی به سرور
scp server/downloads/{GymPro-Setup.exe,info.json,GymPro-Setup.exe.sha256} root@194.56.148.100:/var/www/gym-admin/downloads/
```

`server/downloads/` در `.gitignore` است (فایل ۱۷۰ مگابایتی وارد گیت نمی‌شود).

## نکات پیاده‌سازی
- لندینگ HTML خالص است (بدون React/Next) تا در همان پروسهٔ `admin.mjs` و بدون وابستگی سرو شود.
- متادیتای دانلود با `fetch('/download/info.json')` پر می‌شود؛ اگر در دسترس نبود، صفحه بدون خطا می‌ماند.
- لندینگ با `cache-control: public, max-age=300` سرو می‌شود؛ پس از تغییر، ۵ دقیقه تا دیده شدن فاصله است.
- تصاویر با `cache-control: public, max-age=86400`.
