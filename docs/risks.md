## ریسک‌هایی که با تصمیم معماری حذف شدند (به‌جای حل‌شدن)

- **XSS → دسترسی فایل:** با `sandbox:true` + `contextIsolation` + `connect-src 'none'`، حتی XSS در
  رندرر هم به فایل/شبکه نمی‌رسد. تنها راه نفوذ، IPC است که ورودی‌اش Zod می‌خورد.
- **نشت اعتبارنامه:** هیچ توکن API در رندرر نیست؛ کلیدهای SMS/لایسنس فقط در Main.
- **پروکسی MITM روی آپدیت:** امضای Ed25519 مستقل از TLS؛ TLS فقط برای محرمانگی، نه اعتماد.
