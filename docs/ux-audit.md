## ایرادهای پیدا‌شده و اصلاح‌شده

| # | ایراد | اصلاح |
|---|---|---|
| ۱ | فیلدهای فرم نام دسترس‌پذیر نداشتند (`Field` فقط `span.label` می‌ساخت) | `Field` حالا `<label for>` واقعی می‌سازد و `aria-label`/`id` را به کنترل تزریق می‌کند؛ `TextArea` هم propها را عبور می‌دهد |
| ۲ | ۷۲ دکمهٔ کوچک‌تر از حد استاندارد (بخش‌های تنظیمات، سوییچ‌ها) | `min-height: 32px` برای `.btn`، سرتیتر بخش‌ها و سوییچ |
| ۳ | اسکریپت بازبینی، `color-mix()` را اشتباه می‌خواند و ۶ «کنتراست پایین» جعلی می‌ساخت | پارسر رنگ بازنویسی شد (پشتیبانی `color(srgb …)` + ترکیب آلفا) — نتیجه: صفر نقض واقعی |
| ۴ | فیلتر وضعیت در «اعضا» برچسب نداشت | لیبل متنی «وضعیت» + `aria-label` |
| ۵ | جستجوی بالای صفحه با جستجوی جدول اشتباه می‌شد | نام و آیکون به «پرش سریع» (Ctrl+K) تغییر کرد؛ جستجوی داده در جدول ماند |
| ۶ | «نزدیک انقضا: ۰» با ردیف‌های «۳۰ روز مانده» ناسازگار به نظر می‌رسید | معیار یکسان شد: «انقضای ۷ روز آینده» با tooltip توضیحی |
| ۷ | «بدون قرارداد» قرمز بود (هشدار بی‌مورد) | به زرد تغییر کرد؛ قرمز فقط برای قرارداد منقضی |
| ۸ | «مانده» و «#» مبهم بودند | «روز باقی‌مانده» و «شماره» |
| ۹ | سرستون‌های جدول از بدنه جدا نبودند | پس‌زمینهٔ ملایم + وزن ۷۰۰ |
| ۱۰ | اعداد محور نمودار لاتین و بدون جداکننده | `compactMoney` با ارقام فارسی («۳٫۳ م») + گام محور X |
| ۱۱ | نمودار درآمد با یک پرداخت، تنها یک نقطه نشان می‌داد | سری ۳۰ روزه با صفر‌پرکردن (`reports.series`) |
| ۱۲ | تغییر رنگ تم، سطوح (سایدبار/هدر) را رنگی نمی‌کرد | حالت «رنگ‌آمیزی کامل رابط» + `--brand-wash`/`--brand-line` با کنتراست حفظ‌شده |
| ۱۳ | تعویض تم از مسیری غیر از دکمه، رنگ تم را کهنه می‌گذاشت | `MutationObserver` روی `data-theme` رنگ را بازمحاسبه می‌کند |

## محدودیت‌های پذیرفته‌شده (عمدی)

- **صفحه‌بندی و انتخاب گروهی** در جدول اعضا نیست: سقف ۱۰۰ رکورد آخر نمایش داده می‌شود و تعداد زیر جدول نوشته می‌شود. برای باشگاه (چند صد عضو) کافی است؛ اگر لازم شد، فاز بعد.
- **مرتب‌سازی ستونی** فقط برای پیش‌فرض (جدیدترین اول) است.
- رنگ‌های سبز/زرد/قرمز **معنایی**اند و با تغییر رنگ تم عوض نمی‌شوند (این خواستهٔ استاندارد است، نه باگ).
- گزارش خودکار axe-core اجرا نشده؛ سنجه‌های دسترس‌پذیری دستی و هدفمند پیاده شده‌اند.
