# جیم‌پرو (GymPro) — نرم‌افزار مدیریت باشگاه

اپلیکیشن دسکتاپ **آفلاین و پرتابل** ویندوز ۱۰/۱۱ برای مدیریت باشگاه بدنسازی.
Electron 44 + Next.js 15 (static export) + SQLite (`node:sqlite`) — بدون هیچ وابستگی native و بدون سرور محلی.

## اجرای سریع (توسعه)

```bash
npm install
npm run dev          # بیلد + اجرای برنامه با ابزار توسعه
npm run smoke        # تست دود انتها‌به‌انتها روی پایگاه داده و منطق تجاری
npm run build        # بیلد UI + باندل main/preload
npm run dist         # ساخت خروجی پرتابل: dist/GymPro-Portable-1.0.0.exe
```

> **نکتهٔ npm 11:** نصب باینری Electron ممکن است به‌دلیل مسدود بودن `postinstall` انجام نشود.
> در آن صورت `node_modules/electron/dist` را از یک نصب سالم کپی کنید و در `node_modules/electron/path.txt` مقدار `electron.exe` را بنویسید.

## ساختار

```
app/                     روت‌های Next (یک صفحه؛ ناوبری داخلی با حالت + هش)
components/App.tsx       پوسته: ورود، سایدبار، Command Palette، تور، میان‌برها
components/views/*       ۱۴ ماژول مستقل (اعضا، قرارداد، مالی، تردد، کیوسک، بوفه، …)
apps/desktop/src/        فرآیند اصلی: paths، db، repo، ipc، license، updater، support، backup، smoke
packages/db/migrations/  DDL واقعی (۴۴ جدول + schema_migrations که migrate() می‌سازد)
lib/                     منطق مشترک: تقویم شمسی، قالب‌بندی پول، کلاینت IPC، Zustand
server/                  بک‌اند امضا/لایسنس/آپدیت/تیکت (بدون وابستگی، قابل استقرار روی VPS)
legal/                   حریم خصوصی، قوانین، کوکی
docs/                    معماری، بک‌اندها، ریسک‌ها، انطباق حقوقی، اسکرین‌شات‌ها
```

## داده‌ها کجا ذخیره می‌شوند؟

۱. حالت پرتابل: پوشهٔ `data` **کنار فایل exe** (پایگاه داده، پشتیبان، عکس، پیوست، لاگ، آپدیت).
۲. اگر آن پوشه قابل نوشتن نبود (فلش قفل، OneDrive): `%APPDATA%/GymPro/data` + هشدار در برنامه.

## امنیت (خلاصهٔ اجراشده)

- `contextIsolation: true`, `sandbox: true`, `nodeIntegration: false`.
- Preload فقط سه تابع و فقط کانال‌های ثبت‌شده در main را می‌شناسد؛ کانال ناشناس → `E_CHANNEL`.
- هر هندلر ورودی را با Zod می‌سنجد؛ خطاها پیام فارسی دارند، نه stack.
- رندرر با `app://gympro` (scheme استاندارد و secure) با CSP سخت‌گیرانه (`connect-src 'self'`, `frame-src 'none'`) سرو می‌شود؛ مسیرها با path-traversal guard.
- رمز/PIN با scrypt (salt جدا) ذخیره می‌شود؛ توکن QR فقط به‌صورت SHA-256.
- لایسنس با Ed25519 امضا و **هر بار در استارتاپ** اعتبارسنجی می‌شود؛ کلید خصوصی فقط روی سرور است.
- هیچ ترکر/آنالیتیکس/امبد ثالثی وجود ندارد.

## بازیابی رمز عبور (بدون اینترنت)

رمزها با `scrypt` هش می‌شوند؛ خواندن رمز ممکن نیست. سه راه بازگشت:

1. **کد بازیابی** — هنگام راه‌اندازی اولیه یک‌بار نمایش داده می‌شود (۲۰ کاراکتر، `K7QM-3XPD-9RTB-W2HN-5JVC`). در صفحهٔ ورود → «رمز عبور را فراموش کرده‌ام» → تبِ کد بازیابی. هر کد یک‌بارمصرف است و پس از استفاده کد جدید صادر می‌شود.
2. **توکن پشتیبانی** — اگر کد را نداری، شناسهٔ دستگاه (صفحهٔ لایسنس) را برای فروشنده بفرست:
   ```bash
   node server/make-recovery.mjs <machineId> <username> 60
   ```
   خروجی، متن توکن و امضاست؛ در برنامه در تبِ «توکن پشتیبانی» جای‌گذاری می‌شود. توکن به همان دستگاه و همان کاربر گره خورده و منقضی می‌شود.
3. **مالک باشگاه** — تنظیمات → کاربران → «بازنشانی رمز» (بدون نیاز به رمز قبلی، با ثبت در گزارش حسابرسی).

برای دیدن حساب‌های موجود روی یک نصب (نام کاربری و نقش، بدون رمز):

```bash
node scripts/show-users.mjs "C:\path\to\data"
```

## «مرا به خاطر بسپار»

کلید عبور ذخیره **نمی‌شود**. یک نشانهٔ نشست ۳۰ روزه در `data\.session` نوشته می‌شود که با DPAPI ویندوز (`safeStorage`) رمزگذاری شده است. با «خروج»، تغییر رمز، یا باطل‌شدن کاربر، نشست خودکار پاک می‌شود.

## رنگ تم (تغییر توسط کاربر)

تنظیمات → **ظاهر برنامه**: هشت رنگ آماده + انتخاب رنگ دلخواه. رنگ انتخاب‌شده در `settings` (کلید `ui.accent`) و در `localStorage` ذخیره می‌شود و در هر دو تم روشن/تاریک اعمال می‌گردد.

مهندسی پشت آن (`lib/theme.ts`): رنگ انتخابی خام استفاده نمی‌شود؛ روشنایی (L) آن تا رسیدن به **۴٫۵:۱** در برابر پس‌زمینه تنظیم می‌شود و رنگ متن دکمه (سفید یا تقریباً سیاه) بر اساس بیشترین کنتراست انتخاب می‌شود. برای استفاده‌نشدن رنگ‌های ناخوانا (زرد، خاکستری روشن) این اصلاح خودکار است. صحت‌سنجی:

```bash
node scripts/check-accents.ts   # ۱۶ ترکیب رنگ×تم + ۴ ورودی خصمانه → ALL PASS
```

## استفاده از کامپوننت‌های 21st.dev

`lib/utils.ts` تابع استاندارد `cn()` را دارد و وابستگی‌های shadcn (`clsx`, `tailwind-merge`, `class-variance-authority`) نصب‌اند، بنابراین قطعه‌های 21st/shadcn با کمترین تغییر در پروژه کار می‌کنند:

```bash
npx @21st-dev/cli login                  # یک‌بار
npx @21st-dev/cli search "stats card"
npx @21st-dev/cli get <id>               # کد و لیست وابستگی‌ها
npx shadcn@latest add "https://21st.dev/r/<owner>/<component>?api_key=$API_KEY_21ST"
```

الگوی کارت KPI در این پروژه از کامپوننت *Stats Card* الهام گرفته و به توکن‌های خودمان (`--brand`, `--panel`, `--muted`) و RTL بازنویسی شده است — بدون `framer-motion` و بدون وابستگی به توکن‌های `text-primary`/`bg-card`؛ دلیلش: CSP سخت‌گیرانه، حجم بیلد و حفظ کنتراست AA.

## عبور از هشدار SmartScreen (برای مشتری)

فایل exe امضای کد تجاری ندارد، بنابراین ویندوز ممکن است هشدار آبی نمایش دهد:

1. روی **More info** کلیک کنید.
2. دکمهٔ **Run anyway** را بزنید.
3. در صورت نیاز، پوشه را در Windows Security → Protection history → Allow on device اضافه کنید.

برای حذف کامل هشدار، در فاز انتشار یک گواهی Code Signing (OV/EV) تهیه و در `electron-builder.yml` به‌صورت `win.signingHashAlgorithms`/`certificateFile` تنظیم کنید. تا آن زمان، هشدار طبیعی است و نشانهٔ ویروس نیست.

## بک‌اند (لایسنس / آپدیت / تیکت)

```bash
node server/index.mjs                                  # API برنامه        http://127.0.0.1:8787
ADMIN_PASSWORD='رمز-قوی' node server/admin.mjs         # پنل مدیریت         http://127.0.0.1:8899
node server/make-key.mjs GP-DEMO-0001 pro 12 2 "نام خریدار"
node server/publish.mjs 1.0.1 dist/GymPro-Portable-1.0.1.exe mandatory
```

- `POST /v1/activate` → بدنهٔ لایسنس امضاشده (محدودیت اسلات فعال‌سازی، rate limit).
- `POST /v1/deactivate` → آزادسازی اسلات دستگاه.
- `GET /latest.json` → مانیفست امضاشدهٔ آپدیت (کلاینت sha256 + امضا را قبل از نصب می‌سنجد).
- `POST /v1/tickets`, `GET /v1/tickets/:id` → تیکتینگ آفلاین-اول.

**پنل مدیریت (`server/admin.mjs`)** — برای ساخت لایسنس، دیدن دستگاه‌های فعال، صدور توکن بازیابی رمز، انتشار آپدیت و پاسخ به تیکت‌ها. بدون هیچ وابستگی npm، پشت nginx و pm2 اجرا می‌شود. راهنمای کامل گردش کار فروش: `docs/admin-panel.md`.

کلید خصوصی `server/keys/license-private.pem` است: **آن را در مخزن عمومی قرار ندهید** و برای تولید، کلید تازه بسازید.
